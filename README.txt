Upload all three files to the ROOT of the public GitHub repository:
https://github.com/clearmyrecord/vegas-ski-shuttle

Then visit https://vegasskishuttle.com/weather.html once the domain's DNS/HTTPS configuration is resolved.
The standalone weather page does not replace your existing homepage or booking features.

To add a navigation link on the homepage, add:
<a href="weather.html">Detailed weather reports</a>

Forecast source: National Weather Service API (api.weather.gov), no API key required.
The site loads upcoming forecast periods, NOT live weather observations or ski resort snow-depth measurements.
For snow depth, lifts, and closures, follow each resort's official link.
Some browser privacy extensions, service interruptions, or NWS API limitations may prevent forecasts from loading; the official links remain available.
